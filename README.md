# AutoReadPaper

围绕研究主题定期发现 arXiv 论文，解析全文，通过可配置的大模型生成带原文引用的图文阅读报告，整理为本地论文库。

首版本地应用已可运行。默认不启用模型调用；在「设置」中配置并启用。界面优先使用下拉列表。

## 启动

需要 Python 3.11+、Node.js 20+。首次安装：

```bash
./scripts/setup.sh
./scripts/start.sh
```

打开 http://127.0.0.1:8765 。服务只监听本机。Ctrl+C 停止服务与阅读进程。电脑休眠、关机或进程退出期间不会执行任务；重启后恢复待处理任务，调度器检查到期主题。当前没有安装开机启动服务。

已有安装可直接运行 `./scripts/start.sh`。端口冲突时用 `./scripts/start.sh --port 8767`。可用 `PYTHON_BIN=/path/to/python3 ./scripts/setup.sh` 指定 Python。

## 接入大模型

在「设置 → 大模型接入方式」选择一种方式，所有主题共用该连接。

### API 服务

1. 填写 Base URL（例如 `https://api.openai.com/v1`）与 API Key。
2. 点击「保存连接并获取模型列表」，下拉选择正文模型及可选视觉模型。服务不提供模型列表时，可在高级设置手动填写模型 ID。
3. 启用模型阅读、保存设置，点击「测试一次调用」，在任务中心查看结果。

当前支持 OpenAI 兼容的 Chat Completions 协议，包括采用该协议的其他供应商或本地模型服务。不是所有服务商的原生 API 都兼容。图片输入、JSON 输出和 token 参数需由对应服务支持；高级设置可调整兼容参数。无鉴权本地服务可不填 Key。原生 Responses / Anthropic / Gemini 协议尚未实现。

Key 仅保存在本地数据目录的 `settings.json`（文件权限 600），浏览器 API 不回传原 Key；这不是系统钥匙串加密。也可通过 `ARP_API_KEY` 环境变量覆盖。启用后，论文文字与选择的图表页发送至配置的模型服务。

### 本机 Codex CLI

1. 安装新版 Codex CLI，在普通终端运行 `codex login`，完成登录。
2. 下拉选择「本机 Codex CLI · 使用已有登录」，点击「检测 CLI 与登录状态」。
3. 选择 CLI 默认模型，或手动指定模型；需要图表解读时勾选图片选项。必要时在高级项填写 CLI 完整路径。
4. 启用并保存，点击「测试一次调用」。

应用以非交互 `codex exec` 调用本机 CLI，复用 CLI 自己管理的认证，无需在本工具再填 Key。采用临时、只读会话及结构化输出，关闭无关工具和插件，不加载自定义 CLI 配置。已实测 CLI 0.161.0；旧版可能不支持所需参数。CLI 仍调用远端模型，用量受登录账户额度约束，并非本地离线模型或无限免费调用。

CLI 模式的 token 额度用于调用前检查与调用后记账，不能硬性截断单次实际用量。如果提示 CLI 初始化权限错误，请从普通终端启动本地服务，并确认 CLI 的运行目录权限。

参考：[Codex 非交互运行](https://learn.chatgpt.com/docs/non-interactive-mode)、[Codex 登录方式](https://learn.chatgpt.com/docs/auth)。

## 日常使用

- 创建主题：关键词、排除词、关注问题；选择每日、每周或手动检索，以及回溯时间和每日篇数。
- 可手动扫描主题，或导入 arXiv 链接、编号及本地 PDF。
- 阅读任务解析 PDF、分块阅读正文、解读选定图表页；报告包含原文摘录、页码与位置。没有模型时保留论文和解析结果，任务明确显示等待配置。
- 论文库支持主题、阅读状态、收藏、全文搜索；详情可记笔记、查看版本、重读及导出含 Markdown、JSON、图表和可选 PDF 的 ZIP。
- 任务中心显示进度、失败原因、重试和取消。数据、队列、模型调用记录持久保存在本地。

## 架构与数据

React + TypeScript + Vite 界面，FastAPI API，独立 Python worker，SQLite WAL / FTS5，PyMuPDF 解析。默认数据目录为项目下 `data/`；可用 `--data-dir /path/to/data` 或 `ARP_DATA_DIR` 改变。备份时先停止服务，再复制整个数据目录。

```bash
# 独立 worker / 单次清空当前就绪队列，供将来的外部调度使用
.venv/bin/python -m autoreadpaper.cli worker
.venv/bin/python -m autoreadpaper.cli run-once
# 已单独运行 worker 时，API 不再创建第二个 worker
./scripts/start.sh --no-worker
```

单机单 worker；数据库租约、重试、阶段调用缓存和扫描检查点用于中断恢复。Dot 云端部署尚未验证，不包含公网认证或多用户权限。

## 验证与边界

```bash
.venv/bin/python -m pytest -q
npm --prefix web run build
```

40 项自动化测试覆盖导入去重、调度、引用校验、任务恢复、额度、模型适配、归档与导出等；大部分模型测试使用可控响应。另已实际检索并下载 DROID-SLAM（arXiv:2108.10869v2），解析 15 页，以已登录 Codex CLI 完成 3 块正文及 2 页图表阅读，归档 27 条内容。引用字符串校验通过不等于所有总结结论已获人工事实核验；尚未开展 20 篇论文质量评估，也未实测第三方 API 服务。

当前发现源为 arXiv；不抓取整个互联网。图表展示为原文整页预览，尚无精确图形裁切或 OCR；扫描件、复杂排版可能解析不完整。报告速览通过独立的全文笔记综合阶段生成，覆盖研究问题、核心方法、主要结果及局限，并保留原文依据。全文范围标签表示解析及引用检查范围，不保证语义正确；需要回到原文核对关键结论。无视觉模型时只展示原图与提取的图注。预算是 token/篇数约束，不是精确费用上限。


## 质量评分与推荐阅读

全文报告归档后，对已关联且未排除的研究主题自动创建评分任务。现有报告可在「推荐阅读」点击「为已处理论文补充评分」。未归入主题的论文需要先关联主题；候选元数据不生成质量分。失败或等待预算的评分任务可在任务中心处理。

模型按 0–5 分、0.5 步进评价：方法创新性 25%、指标效果 25%、实验严谨完备 30%、主题相关性 20%。锚点为 0 明显无效／不相关，1 弱，2 有限，3 扎实，4 强，5 极强且须充分证据。指标比较应考虑训练数据、算力及评测条件；实验严谨性考虑公平基线、消融、泛化、样本量、不确定性与失败分析。创新性仅依据论文内容，不是外部查新。

阅读优先分 = Σ(维度分 / 5 × 权重)，满分 100。研究质量分只将前三项按总权重 80 归一化。相关性针对主题单独评分；任一维度证据不足时不产生阅读优先分，部分全文报告只保存暂定评估，不进入推荐榜。置信度单独展示，取四维最低值，不暗中调整总分。

「推荐阅读」是站内优先清单，默认未读、按阅读优先分降序，同分按入库时间降序；全部主题下取每篇最高匹配主题分，也可下拉限定主题。切换主题配置、论文版本或报告修订后，旧分数自动退出当前排序；可补充评分。历史记录保留。导出 ZIP 包含该报告的评分 Markdown 和 JSON。评分属于模型辅助初评，不是录用概率、客观定论或独立复现结论。首版固定权重，未进行跨大样本人工校准；没有启用邮件或系统通知推送。

主题仅分为保留与删除，不再提供归档。暂停／恢复只控制定时检索，不隐藏主题和已评分报告。删除主题会取消其待处理任务并解除主题关联，保留论文、报告、笔记与历史记录；界面删除前会确认。旧版已归档主题会自动恢复显示，定时检索保持暂停。


## 清理论文库

在「论文库 → 清理论文库」选择未生成报告、已读、低阅读优先分或全部论文，配合主题、入库时间下拉筛选。默认保护收藏和有笔记的论文。先预览，再逐篇勾选，并输入“删除 N 篇”确认永久删除；本功能没有回收站。

清理移除选定论文的全部版本、报告、评分、笔记、搜索索引、主题关联和应用保存的原文／预览文件，取消相关任务。主题配置保留；已导出的独立 ZIP、历史检索缓存与用量账本不删除。低分模式不把未评分论文当作低分。限定主题只是选择条件，删除针对整个论文库；以后检索仍可能重新发现已删除论文。

预览有效期 10 分钟，期间数据或保护状态改变需重新预览；存在运行任务时暂不执行清理。数据库删除完成后若部分文件移除失败，会明确提示，并在服务重启时重试，不移除后来重新导入而被使用的文件。测试仅在隔离临时目录执行；添加功能本身不会清空现有库。
